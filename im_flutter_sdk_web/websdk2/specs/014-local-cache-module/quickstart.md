# 快速验证指南（Quickstart）

本指南用于验证本地缓存模块是否满足规格中的三条用户故事。

## 预置条件

- 已接入本地缓存模块并暴露统一读写接口
- 可模拟服务端数据返回
- localStorage 可正常读写

## 场景 1：首屏快速展示会话摘要（P1）

1. 向缓存写入至少 1 条会话摘要与最后消息。
2. 重启或重新初始化 SDK。
3. 观察初始化时是否直接读到缓存并渲染会话列表。
4. 模拟服务端同步返回不同内容，确认本地缓存被覆盖并触发更新。

**预期**：在服务端响应前即可显示缓存；服务端结果到达后会更新并回写。

## 场景 2：业务模块批量读写（P2）

1. 准备一批用户信息与会话摘要。
2. 通过缓存模块批量写入。
3. 通过批量读取接口获取数据并对比一致性。

**预期**：批量读写可用且一致；会话摘要包含 lastMessage 即可满足首屏展示。

## 场景 3：淘汰与过期控制（P3）

1. 写入大量缓存数据直到触发 `QuotaExceededError`。
2. 继续写入，触发 TTL + LRU 清理并重试一次。
3. 检查会话缓存是否仍保留，用户信息是否优先淘汰。
4. 将缓存时间推进超过 TTL，再次读取。

**预期**：触发超限时执行清理并仅重试一次；会话优先保留；过期数据不再返回。
