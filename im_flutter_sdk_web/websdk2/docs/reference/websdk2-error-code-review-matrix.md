# Web SDK2 / Android 错误码 Review Matrix

生成时间：2026-05-20

当前状态更新：2026-05-26。本文保留 Web/Android review matrix 审计视角；用户侧公开错误码入口以 `docs/reference/error-codes.md` 为准，治理约束由 `npm run errors:check` 校验。

Web 来源：`src/utils/error-codes.ts`、`src/rest/api-errors.json`、`docs/reference/api-error-reference.md`。

Android 来源：Android `EMError` API 文档（hyphenate_SDK4.0 4.21.0）：https://doc.easemob.com/apidoc/android/chat3.0/classcom_1_1hyphenate_1_1_e_m_error.html。

说明：主表以 Web SDK 当前 `ERROR_CODES` 的数值去重；同一数值下多个 Web 别名用 `<br>` 合并展示。Push 公开码已收敛到服务端/移动端同号 `1501/1502`，但 Web 保留免打扰/语言设置语义常量名。

## Review 摘要

- Web `ERROR_CODES` 当前共 133 个导出别名，去重后 99 个数值。
- Android `EMError` 文档共 120 个静态错误码常量。
- Web 当前更适合按 `canonical code` 理解，而不是按内部别名理解；详见 `docs/reference/error-code-governance-checklist.md`。
- 通用、鉴权、连接、文件、消息、群组、聊天室、用户资料、Presence、翻译、Reaction 的大部分数值与 Android 对齐。
- `206/207/216/217/218/220` 已按旧 Web SDK / 移动端语义补齐，连接断开事件会附带 `errorCode/errorMessage`。
- `USER_MUTED_BY_ADMIN` 已对齐到 `219`，`USER_NOT_ON_ROSTER` 已对齐到 `221`。
- Push 已收敛为 `1500/1501/1502`；其中 `1501/1502` 与 Android 同号，但 Web 常量名按免打扰/语言设置语义保留。
- Web 的语音转文字 `-3/50/52/410/411`、用户资料订阅 `1600/1601`、联系人同步 `1700-1704` 是 Web/服务端扩展，Android `EMError` 文档未列出同值常量。
- `EM_NO_ERROR=0` 与 `PARTIAL_SUCCESS=7` 当前都未作为 Web 公开错误码导出；其中 `0` 应视为成功态，`7` 仅适合部分成功结果型 API。

## 治理口径

- 公开文档优先按 `canonical code` 组织，不再把所有内部别名都当成同等级公开错误码。
- 对同语义不同编号的项，优先补兼容说明，不急于立即改号。
- Android-only 错误码需要分成四类理解：
  - 已被 Web 归并处理
  - 更适合走连接事件而非普通业务错误
  - 不在当前 Web SDK 产品面
  - 疑似实现缺口，需补审计
- 详见 `docs/reference/error-code-governance-checklist.md`。
